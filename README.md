# Nimclea Orange

**A deterministic control layer for AI agents.**

Human authority before agent action.
Evidence before release.
STOP before mutation.

## Why Orange

As AI systems move from generating answers to taking actions, a fundamental question becomes increasingly important:

**Before an agent acts, how do we prove that it has the authority to do so?**

A prompt is not authority.
A completion claim is not evidence.
A protected action should pass through a deterministic gateway before mutation.

Nimclea Orange is designed to make authority boundaries, evidence requirements, and execution conditions explicit before an AI agent action is released.
